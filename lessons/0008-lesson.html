变化率、导数与雅可比：改一点会怎样

从差值理解导数，解释残差为什么会随状态改变。

先修：02 · 先认识问题：机器人到底不知道什么；07 · 矩阵与旋转：展开后就是乘法和加法

预计用时：2 次 × 40 分钟。一次学不完就分开，第二天先闭卷重做上一段。

本课新词（4 个）：导数 derivative、偏导 partial derivative、雅可比 Jacobian、线性化 linearization。随时可查 术语页。

先打个比方

开车时把油门踩下一点点，车速变化多少？这个“改一点点输入，输出跟着变多少”的比例就是导数。雅可比只是把很多个油门、很多个仪表盘的比例排成一张表。

比喻只帮你建立直觉；下面用数字、公式和代码把它说准确。

比方→具体问题→手算→代码→解释

从实际问题走到公式

把位置从 6 米改到 6.1 米，到墙的预测距离从 4 米变为 3.9 米。位置增加 0.1，距离减少 0.1。因此“输出变化/输入变化”是 −1。这就是变化率。导数描述改动非常小时的局部变化率。

h′(x) ≈ [h(x+ε)−h(x)] / ε

撇号 ′ 表示导数，ε（读 epsilon）是很小的改变量，分数线就是除法。对 h(x)=10−x，任何非零 ε 都给 −1。对 f(x)=x²，在 x=3、ε=0.01 时，(3.01²−3²)/0.01=6.01；改得更小会趋近 6，所以 f′(3)=6。

为什么关心局部？把弯曲函数在当前位置附近当成直线，就容易计算修正量。写成 f(x+δ)≈f(x)+f′(x)δ。δ 是打算改多少，≈ 是近似相等。对 x² 在 3 附近，δ=0.1，线性预测 9+6×0.1=9.6，精确值 9.61。δ 太大，误差就不能忽略。

有多个输入时，先固定其他量，只改变一个量，叫偏导数。把多个输出对多个输入的偏导排成表，就是雅可比矩阵 J。例如观测 h(x,m)=m−x 对 [x,m] 的雅可比是 [−1,1]：第一列回答改 x，第二列回答改 m。输出 1 个、输入 2 个，J 就是 1×2。

这张表不是“高等数学装饰”：它把测量误差翻译成状态应该怎么改。米对米的导数无量纲；米对弧度的导数单位是米/弧度。数值验证时 ε 太小会受浮点误差影响，太大会偏离局部，应该比较几个量级。

把公式落实到每行代码

Python：可直接运行。先写下预测，再运行核对。

def h(x):
    return 10.0 - x

x = 6.0
eps = 0.001
j = (h(x + eps) - h(x)) / eps
print(round(j, 6))

先算右移后的测量，再减原测量，最后除以移动量；输出 −1.0。若正负号错，更新状态时可能越改越差。

先独立作答，再打开提示

f(x)=x²，x=2，ε=0.01 时数值导数是多少？局部精确导数是多少？

提示：只给下一步

先算 2.01²=4.0401。

核对解答与常见错因

(4.0401−4)/0.01=4.01，精确导数 4。数值差分只是近似，不要求逐位等于精确导数。
