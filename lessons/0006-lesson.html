概率与方差：承认测量不是完全准确的

区分随机抖动、固定偏差和不确定性，理解为什么不能总取平均。

先修：01 · 先认识问题：机器人到底不知道什么；02 · 读懂一段程序，而不是只会启动它

具体问题→手算→公式→代码→解释

从实际问题走到公式

在同一位置测墙距得到 2.9、3.0、3.1 米。真实距离没变，读数却在变。把测量写成 z=真实距离+误差。误差可包含随机抖动，也可包含始终多 0.2 米的固定偏差。多测几次取平均能减小独立随机噪声的影响，但不能自动消除固定偏差。

均值 μ=(z₁+…+zₙ)/n；方差 σ²=平均[(z−μ)²]

μ（mu）是平均值；n 是数量；省略号表示中间项继续相加；σ（sigma）是标准差，σ² 是方差。三个数平均为 3，偏差为 −0.1、0、0.1，平方后平均为 0.006667 米²，标准差约 0.08165 米。这里描述这三个数的整体分散程度，分母用 n；用样本估计总体方差时常见 n−1，不能混用两种目的。

概率描述某种结果有多可能，范围 0 到 1。两种互斥且包含全部情况的结果，概率相加为 1。连续位置的概率通常通过区间表达；某个精确点的概率和概率密度不是一回事。高斯分布是一种中间高、两侧低的误差模型，由均值和方差描述；它是建模选择，不能把所有跳点都当高斯噪声。

二维位置的不确定性用协方差矩阵表示：对角线分别是 x、y 的方差，非对角项描述两者误差是否一起变化。非对角项为 0 不总意味着独立；在联合高斯假设下才有这样的推论。

贝叶斯更新就是把新证据加入原有判断。例：两个房间初始各 0.5 概率；在 A 看见红门概率 0.8，在 B 是 0.2。看见红门后，未归一化权重是 0.4 和 0.1，除以总和 0.5，得到 A 为 0.8、B 为 0.2。归一化只是让总概率回到 1；证据模型错了，答案也会错。

把公式落实到每行代码

values = [2.9, 3.0, 3.1]
mean = sum(values) / len(values)
variance = sum((z - mean)**2 for z in values) / len(values)
print(round(mean, 4), round(variance, 6))

sum 把数相加，len 计数；括号内 for 表示为每个 z 计算一个平方再求和。输出 3.0 0.006667。方差单位是米²，不能直接加在米上。

先独立作答，再打开提示

所有读数都增加 0.2 米，均值和上述方差各如何变化？

提示：只给下一步

每个数到新均值的距离是否改变？

核对解答与常见错因

均值变成 3.2 米，方差不变。若认为方差变大，混淆了“整体偏移”和“分散程度”。
