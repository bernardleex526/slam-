从实际问题走到公式

程序只是按顺序处理数据的一组指令。运行成功只能说明机器执行了这些指令，不保证指令符合物理。我们从第 1 课的残差开始，不同时学习大型库。

变量为数据命名；列表按顺序保存多个数据；循环对每个数据重复操作；函数把一段操作定义为可以多次调用的规则。Python 用缩进表示哪些行属于循环或函数。# 后面的文字是注释，不执行。

下面把 3 次测距放在列表里。for z in measurements 的意思是依次让 z 取 2.9、3.0、3.1。return 把函数的结果交回调用位置；print 把结果显示出来。函数定义本身不等于已经计算。

float 表示带小数的数，计算机用有限精度近似储存；int 表示整数；str 表示文字。"3" 是文字，不能直接当作 3 米参与减法。比较是否相等用 ==。平方在 Python 用 **2，不是 ^2。

运行方式：把代码存为 example.py；在该文件所在目录打开终端（接收命令的窗口），输入 py example.py，Linux/macOS 通常用 python3 example.py。这条命令让 Python 解释器执行文件，不会自动下载任何东西。若找不到 Python，可先完成网页实验；安装时使用 Python 官方发布源。

看到 NameError，找未定义或拼错的变量；TypeError，检查是不是把文字当数字；FileNotFoundError，检查文件路径。报错一般包含文件名、行号和异常类型，先读末行，再回到对应行。不要靠修改随机参数处理程序错误。

把公式落实到每行代码

def residual(position, measured):
    predicted = 10.0 - position
    return predicted - measured

measurements = [2.9, 3.0, 3.1]
for z in measurements:
    print(round(residual(7.0, z), 2))

第一次调用 position=7.0、measured=2.9，预测 3.0，返回 0.1；接着是 0.0、−0.1。round(...,2) 只为显示时保留两位小数，不改变定位模型。

核对解答与常见错因

1.1、1.0、0.9。若写成 0.1、0、−0.1，是忽略了状态改变。若出现很长的小数，是浮点表示，不必先怀疑物理模型。

将墙的位置作为函数的第三个参数，并测试墙 12、位置 8、测量 4。应返回 0。可用 def residual(position, measured, wall): return wall-position-measured。
