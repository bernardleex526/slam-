Python②：列表和循环：一次处理很多测量

能用列表保存多次测量，用 for 循环逐个处理，用 if 跳过可疑数据，并会画追踪表。

先修：03 · Python①：变量、数字和第一次运行

预计用时：2 次 × 30 分钟。一次学不完就分开，第二天先闭卷重做上一段。

本课新词（2 个）：列表 list / 索引 index、循环 loop / 缩进。随时可查 术语页。

先打个比方

列表像一排编了号的快递柜，编号从 0 开始；for 循环像快递员按顺序把每个柜子打开一次，对里面的东西做同样的事。if 就是快递员检查：“这个包裹破了，先放一边。”

比喻只帮你建立直觉；下面用数字、公式和代码把它说准确。

比方→具体问题→手算→代码→解释

从实际问题走到公式

传感器不会只测一次。激光雷达每秒给出几十万个点，IMU 每秒上百条数据。程序必须能“对每个数据做同样的事”。

列表：按顺序装很多个数

measurements = [2.9, 3.0, 3.1] 是一个列表。measurements[0] 取第一个（2.9），measurements[2] 取第三个（3.1），len(measurements) 是个数 3。编号从 0 开始，所以最后一个是 [len−1]；写 measurements[3] 会报 IndexError: list index out of range。

for 循环：对每个元素做同一件事

for z in measurements: 的意思是：依次让 z 等于 2.9、3.0、3.1，每次都执行一遍下面缩进的几行。Python 靠缩进（行首 4 个空格）判断哪些行属于循环。缩进不一致会报 IndentationError。

累加：最常用的循环套路

求和要先准备一个“空篮子” total = 0.0，循环里每次 total = total + z（可简写为 total += z）。循环结束后 total 就是总和。求平均就是总和除以个数。几乎所有 SLAM 代码里的“对每个点算残差再求和”都是这个套路。

if：挑出可疑数据

if z > 5.0: 后面缩进的行只在条件成立时执行。continue 表示“这一个不要了，直接处理下一个”。append 把一个元素加到列表末尾。

追踪表：不运行也能预测输出

下方代码的追踪表：

第几轮zz>5.0？kept 之后
12.9否[2.9]
23.0否[2.9, 3.0]
33.1否[2.9, 3.0, 3.1]
49.0是，打印后跳过不变

画追踪表很慢，但只要练熟 5 次，你读 AI 生成的循环代码就能看出它在干什么。

把公式落实到每行代码

Python：可直接运行。先写下预测，再运行核对。

measurements = [2.9, 3.0, 3.1, 9.0]
kept = []
for z in measurements:
    if z > 5.0:
        print("跳过可疑测量", z)
        continue
    kept.append(z)
average = sum(kept) / len(kept)
print(kept, round(average, 2))

先显示 跳过可疑测量 9.0，再显示 [2.9, 3.0, 3.1] 3.0。sum 是 Python 自带的求和，效果等于自己写累加循环。注意：5.0 这个门槛是我们人为定的，它假设墙不会突然远到 9 米；真实系统里这类门槛都要说明依据，不能随手改。
