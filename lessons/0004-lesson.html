矩阵与旋转：展开后就是乘法和加法

手算二维坐标变换，把矩阵一行对应到代码一行。

先修：03 · 坐标和向量：数字必须带上参考系

具体问题→手算→公式→代码→解释

从实际问题走到公式

机器人位置在地图 (2,1)，朝向比地图 x 轴逆时针转了 90°。传感器看到一个点在自身前方 1 米。这个点在地图哪里？先把“前方”转成地图方向，再加机器人的位置：答案 (2,2)。

角度描述转了多少。绕一圈是 360°，也写成 2π 弧度，π 约等于 3.14159。角度乘 π/180 得到弧度，程序的三角函数通常接收弧度。cos θ 和 sin θ 分别给出单位箭头旋转 θ 后的 x、y 分量。θ=0 时是 (1,0)，90° 时是 (0,1)。

R = [[cos θ, −sin θ], [sin θ, cos θ]]
pᴡ = R pᴮ + t = (c·pₓ−s·pᵧ+tₓ, s·pₓ+c·pᵧ+tᵧ)

R 是 2 行 2 列的矩阵；pᴮ 是机器人坐标下的 2×1 列向量；pᴡ 是地图下的坐标；t 是机器人原点在地图的位置；c、s 分别是 cos θ、sin θ。上标 W、B 是坐标系标签，不是乘方。矩阵乘向量时，每一行与向量对应元素相乘后相加。

90° 时 R=[[0,−1],[1,0]]，R(1,0)=(0,1)，再加 (2,1) 得 (2,2)。矩阵的第一列告诉你原来的 x 单位箭头去了哪里，第二列告诉你 y 单位箭头去了哪里。2×2 乘 2×1 才能得到 2×1；中间的维度必须一致。

逆变换要先减去平移，再反向旋转：pᴮ=Rᵀ(pᴡ−t)。Rᵀ 把行列交换，称为转置；对于旋转矩阵，它也是逆矩阵，即撤销操作。一般矩阵的转置不等于逆。把 (2,2) 减 (2,1) 得 (0,1)，反转 90° 回到 (1,0)。

把公式落实到每行代码

import math
theta = math.radians(90)
c, s = math.cos(theta), math.sin(theta)
px, py = 1.0, 0.0
tx, ty = 2.0, 1.0
wx = c*px - s*py + tx
wy = s*px + c*py + ty
print(round(wx, 6), round(wy, 6))

radians 把度转弧度；第 6 行对应矩阵第一行，第 7 行对应第二行。输出 2.0 2.0。程序没有神秘的“旋转命令”，只是执行刚才展开的四次乘法。

先独立作答，再打开提示

同一位姿，机器人看到点 (0,2)。地图坐标是多少？

提示：只给下一步

90° 旋转把 (0,2) 变成 (−2,0)。

核对解答与常见错因

(−2,0)+(2,1)=(0,1)。若得到 (2,3)，你只加了平移，漏掉旋转。

若还无法解释，回到先修：03 · 坐标和向量：数字必须带上参考系。闭上答案，换一组数字重算。

改变条件的迁移练习与解析

先平移再旋转是否一样？R(p+t) 与 Rp+t 相差 Rt−t，一般不同；用 p=(1,0),t=(2,1),θ=90° 得 (−1,3) 与 (2,2)。
