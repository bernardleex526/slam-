从实际问题走到公式

Python 常用于快速试验，C++ 常用于运行效率和系统集成。这不是重新学一套数学。先把第 4 课的二维旋转搬到 C++，再进入大型项目。

double 是双精度浮点类型；int 是整数类型；分号结束语句；花括号围起函数体。const 表示不能通过该名字修改对象；& 在参数类型中表示引用，即用原对象而不是复制一份。const Vector2d& 适合只读传入向量。

Eigen 是 C++ 线性代数库。Matrix2d 是 2×2 double 矩阵，Vector2d 是两个 double 的列向量，* 执行矩阵乘法。R << 0,-1,1,0 按行填入数值；这里 << 是 Eigen 定义的填充操作，不是数学里的小于。

#include 让编译器看到库声明；main 是程序入口；std::cout 将数据打印到终端。编译把源代码变为机器可运行形式，链接把需要的实现组合起来。头文件找不到先查 include 路径，undefined reference 通常查链接，结果不对则查算法与输入。

完整示例放在 labs/eigen_example.cpp。若 Ubuntu 已有 g++ 和 Eigen 头文件，可运行 g++ -std=c++17 -I/usr/include/eigen3 labs/eigen_example.cpp -o eigen_example，再运行 ./eigen_example。-I 告诉编译器去哪里找头文件，-o 指定输出文件名。这个命令针对 Linux 环境，不是 PowerShell 的安装步骤；本课程没有代你安装编译器。

读取复杂表达式时先写维度。例如 H 是 N×6、δ 是 6×1，则 Hδ 是 N×1，代表每个观测的预测变化。若结果是 6×1，可能把雅可比方向看反。lambda 是就地定义的函数，模板是按类型生成代码的机制；初读时先辨输入输出，再追踪语法细节。

把公式落实到每行代码

#include <Eigen/Dense>
#include <iostream>
int main() {
    Eigen::Matrix2d R;
    R << 0, -1, 1, 0;
    Eigen::Vector2d p(1, 0), t(2, 1);
    Eigen::Vector2d world = R*p + t;
    std::cout << world.transpose() << "\n";
}

输出 2 2。transpose 只为把结果横着打印；world 本身仍是列向量。与第 4 课 wx、wy 两行逐项展开后的结果一致。
