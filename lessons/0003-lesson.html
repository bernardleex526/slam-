Python①：变量、数字和第一次运行

能自己新建一个 .py 文件并运行，读懂赋值、数字类型和最常见的三种报错。

先修：02 · 先认识问题：机器人到底不知道什么

预计用时：2 次 × 30 分钟。一次学不完就分开，第二天先闭卷重做上一段。

本课新词（3 个）：终端 terminal、变量 variable / 赋值、类型 type。随时可查 术语页。

先打个比方

变量像贴了标签的储物盒：wall_m = 10.0 就是把 10.0 放进写着“wall_m”的盒子。之后写 wall_m，程序就去盒子里取值。重新赋值，就是把盒子里的东西换掉。

比喻只帮你建立直觉；下面用数字、公式和代码把它说准确。

比方→具体问题→手算→代码→解释

一步步讲清楚

上一课用 10−3=7 算出了位置。这一课只做一件事：让电脑替你算这一步，并且你能看懂每一行。

第一步：确认 Python 能用

打开终端（Windows 叫“终端”或 PowerShell，Ubuntu 按 Ctrl+Alt+T）。输入 py --version（Windows）或 python3 --version（Linux/macOS）。看到 Python 3.x.x 就可以继续；提示找不到命令，就到 Python 官网安装，安装时勾选“Add Python to PATH”，然后重新打开终端。

第二步：新建并运行文件

用任意编辑器（推荐 VS Code）新建 step1.py，粘贴下方代码并保存。在文件所在文件夹打开终端，运行 py step1.py。如果提示找不到文件，是终端所在目录不对，用 cd 文件夹路径 进去即可，不需要重装任何东西。

第三步：读懂这几种写法

= 是赋值：先算右边，再把结果放进左边的名字里。它不是数学里的“相等”；判断相等用 ==。变量名里写上单位（_m 表示米）是工程好习惯，能少犯一半单位错误。

数字有两种：int 整数（如 7），float 小数（如 7.0）。文字叫 str，用引号包住："3" 是文字“3”，不是数字 3。传感器文件里读出来的往往是文字，要先用 float("3") 转成数字。

运算符：+ - * / 是加减乘除；// 是整除（只留整数部分）；** 是乘方，3**2 是 9。注意 ^ 在 Python 里不是乘方。

第四步：看懂报错

报错不可怕，它在告诉你哪一行出了什么事。先读最后一行，冒号前是错误类型，冒号后是原因；再往上找 line 数字，回到那一行。

最后一行写着意思先查什么
NameError: name 'wal' is not defined用了一个从没赋值过的名字拼写，或者赋值写在了使用之后
TypeError: can only concatenate str (not "int") to str文字和数字直接相加用 float() 或 int() 转换
SyntaxError: invalid syntax写法不合规则括号、引号是否成对，是否用了中文标点

中文标点是新手最常见的 SyntaxError 来源：print（x） 用了中文括号，Python 认不出来。

把公式落实到每行代码

Python：可直接运行。先写下预测，再运行核对。

wall_m = 10.0        # 墙的位置，单位米
measured_m = 3.0     # 测距读数，单位米
position_m = wall_m - measured_m
print("位置（米）:", position_m)
print(type(position_m))
text = "3"
print(float(text) + 1)

第 1–2 行把两个已知数放进变量；第 3 行先算右边 10.0−3.0，再把 7.0 存进 position_m；第 4 行显示 位置（米）: 7.0；第 5 行显示 <class 'float'>，说明它是小数；第 7 行把文字 "3" 转成 3.0 再加 1，显示 4.0。追踪表是读程序最好用的工具：每执行一行，就在纸上更新一次每个变量当前的值。

先独立作答，再打开提示

运行前先写出预测：a = 7、b = 2，然后 print(a / b, a // b, a ** b) 会显示什么？

提示：只给下一步

/ 是普通除法，// 只保留整数部分，** 是乘方。

核对解答与常见错因

显示 3.5 3 49。如果把 a ** b 写成 14，是把乘方当成了乘法；如果把 a // b 写成 3.5，是没有区分两种除法。

若还无法解释，回到先修：02 · 先认识问题：机器人到底不知道什么。闭上答案，换一组数字重算。

改变条件的迁移练习与解析

print("3" + 4) 会报什么错？怎样改？会报 TypeError，因为文字和数字不能直接相加。改成 print(float("3") + 4) 得到 7.0；改成 print("3" + str(4)) 则得到文字 "34"。两种都“不报错”，但含义完全不同，所以要先想清楚你要的是数字还是文字。
