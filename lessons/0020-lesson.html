先打个比方

Python 像同声传译：你说一句，它当场翻译一句。C++ 像出书：先把整本书交给编译器一次翻译成机器语言（编译），之后直接读译本（运行）。出书前编辑会把错别字全部挑出来，所以 C++ 很多错误在运行前就会暴露。

比喻只帮你建立直觉；下面用数字、公式和代码把它说准确。

一步步讲清楚

SLAM 系统（FAST-LIO2、ORB-SLAM 等）大多用 C++ 写，因为它运行快、能直接控制内存。你不需要先成为 C++ 高手，但要能读懂关键代码、改动一小处并重新编译。

第一步：准备编译器

需要 Linux 环境：Ubuntu 本机、WSL2 里的 Ubuntu，或后面部署课的 Docker 容器都可以。终端输入 g++ --version，看到版本号即可；没有就运行 sudo apt install build-essential。Windows 原生的 PowerShell 不适合本课命令。

第二步：编译、运行，两步分开

g++ -std=c++17 labs/cpp/01_basics.cpp -o basics
./basics

第一条是编译：把源代码翻译成可执行文件 basics，-std=c++17 指定语言版本，-o 指定输出文件名。第二条是运行，./ 表示“当前文件夹里的”。改了代码必须重新编译，否则运行的还是旧版本。这是新手最常见的“我改了怎么没效果”。

第三步：和 Python 逐行对照

PythonC++区别
wall = 10.0double wall = 10.0;要写类型；每句以分号结束
z = [2.9, 3.0]std::vector<double> z = {2.9, 3.0};列表叫 vector，要说明里面装什么类型
for v in z:for (double v : z) { ... }用花括号表示范围，不靠缩进
print(x)std::cout << x << "\n";<< 把内容依次“推”到屏幕
7 // 2 得 37 / 2 得 3两个整数相除会丢掉小数，要写 7.0 / 2

#include <iostream> 引入输入输出功能，类似 Python 的 import。int main() 是程序入口，运行时从这里开始；return 0; 表示正常结束。std:: 表示这个名字来自标准库。

第四步：读懂一条编译报错

01_basics.cpp:9:9: error: expected ',' or ';' before 'std'

格式是“文件:行:列: error: 原因”。这条说第 9 行第 9 列之前少了逗号或分号。编译器报告的位置常常是错误的下一处，所以要同时看它的上一行。一次出现几十条报错时，只看第一条，修好再重新编译，后面的往往是连锁反应。

对照 Python 读这段 C++（文件：labs/cpp/01_basics.cpp）

C++：需要在 Linux 中编译后运行，命令见上文。

#include <iostream>
#include <vector>

int main() {
    double wall = 10.0;
    std::vector<double> measurements = {2.9, 3.0, 3.1};
    for (double z : measurements) {
        double position = wall - z;
        std::cout << "position = " << position << "\n";
    }
    int a = 7, b = 2;
    std::cout << a / b << " " << 7.0 / 2 << "\n";
    return 0;
}

输出四行：position = 7.1、position = 7、position = 6.9、3 3.5。第二行显示 7 而不是 7.0，是 cout 默认省略多余的零，不是类型变了。最后一行：两个 int 相除得 3，有一个是小数就得 3.5。这个“整数除法”曾让很多 SLAM 代码把时间间隔算成 0。

核对解答与常见错因

g++ 会报 9:9: error: expected ',' or ';' before 'std'，位置在第 9 行开头。因为语句可以跨行，编译器直到看见下一句的开头 std 才确定少了分号。所以要养成习惯：报错行没问题时，看它的上一行。

若还无法解释，回到先修：05 · Python③：函数与调试：把重复写成规则，把报错变成线索；19 · 项目一：真正同时估计位置和地标。闭上答案，换一组数字重算。

改变条件的迁移练习与解析

把 int a = 7, b = 2; 改成 double a = 7, b = 2;，第一个输出会变成什么？会变成 3.5。再想一想：如果时间戳用 int 存毫秒，dt = (t2 − t1) / 1000 会得到什么？间隔不足 1000 毫秒时都是 0，积分就完全不动。应写成 1000.0。
