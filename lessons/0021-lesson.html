VLN：把一句话落到可到达的地方

区分视觉语言理解、目标落地、导航执行和成功判断，建立可评估基线。

先修：10 · 相机：三维点为什么变成二维像素；19 · 导航：地图、路径和控制不是同一个问题；20 · 机器学习：把写规则变成用数据拟合规则

具体问题→手算→公式→代码→解释

从实际问题走到公式

VLN 是视觉语言导航：系统依据看到的环境和语言指令行动，例如“穿过门，在沙发左边停下”。这不仅是把句子转为坐标：门在哪里、哪张沙发、左边以谁为参考、是否已经到达，都需要观测与历史。

可解释的模块方案是：相机图像 → 物体/场景识别 → 结合深度与位姿形成语义地图 → 指令解析为候选目标与约束 → 规划可行路径 → 执行并重新观察 → 判断停止。也有直接从观测和指令预测动作的策略；它不一定显式调用 SLAM。两种路线都要面对错误和评估。

语义地图是在位置之外附上“门、桌子”等意义；落地 grounding是把语言中的对象或关系对应到当前环境实体。检测器框出“门”还不够：一个像素框并不直接给世界坐标，必须结合深度、相机内参、外参和时间。

数值例：某门中心像素 u=520，主点 cₓ=320，焦距 fₓ=400，深度 Z=2 米，则相机 X=(520−320)×2/400=1 米。再用第 9 课变换到地图。若没有深度，可以维护候选射线并继续观察，不能凭像素编造距离。

先做规则基线：图中起点 S 通往 A、B；A 通往红门 R，B 通往蓝门 D；指令“去红门”通过人工标签选择 R，广度优先搜索给出 S→A→R。这是语义目标接口实验，使用的是人工真值标签，不涉及视觉识别、自由语言或学习。

再做真实 VLN 时，替换人工标签，保存每步图像、语言、候选、选择、动作和停止原因；先按 R2R 原任务约定理解数据格式与离散导航，再区分连续运动和真实机器人部署。按未见过的场景划分训练与测试，避免背路线。报告成功率、路径效率和错误停止；成功距离阈值、步数限制与可用传感器必须公开。

单次 SPL = S·L/max(P,L)

S 是成功时 1、失败时 0，L 是最短可行路径长度，P 是实际路径长度；数据集取各任务平均。成功、L=4、P=6 时得 2/3。SPL 是通用导航效率指标，不足以单独评价是否遵从整条语言路线；还需按具体基准报告指令路径一致性等指标。

把公式落实到每行代码

# 人工语义标签的基线；不是视觉或语言模型
labels = {"R": "red door", "D": "blue door"}
goal = next(node for node, label in labels.items() if label == "red door")
success, shortest, actual = 1, 4.0, 6.0
spl = success * shortest / max(actual, shortest)
print(goal, round(spl, 4))

next 取第一个匹配候选，若无匹配会抛错，所以工程代码应处理无候选或多个候选。输出 R 0.6667。实际项目的缺失标签处理见 navigation.py。
