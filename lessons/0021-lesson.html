C++②：函数、引用与 const：数据是复制还是共用

能写带类型的函数，分清按值传递和引用传递，读懂 const 引用，并认识“声明”和“定义”分开写的原因。

先修：20 · C++①：从 Python 到 C++：类型、分号和编译

预计用时：2 次 × 40 分钟。一次学不完就分开，第二天先闭卷重做上一段。

本课新词（2 个）：引用 reference / const、头文件 header。随时可查 术语页。

先打个比方

按值传递像给同事一份复印件，他在上面涂改不影响你的原件；引用传递像把原件直接交给他，他改了你的也变了；const 引用像把原件放进透明展示柜，他能看不能改，又省了复印的时间。

比喻只帮你建立直觉；下面用数字、公式和代码把它说准确。

比方→具体问题→手算→代码→解释

一步步讲清楚

C++ 函数和 Python 的思路一样，只是要写清楚参数类型和返回类型：double residual(double position, double measured) 表示“接收两个小数，返回一个小数”。不返回任何值的函数写 void。

按值传递：拿到的是复印件

默认情况下，函数参数是原数据的副本。函数里改它，外面的变量不受影响。小数、整数复制很便宜，所以这样写没问题。

引用传递 &：拿到的是原件

void shiftAll(std::vector<double>& values, double offset) 中，类型后面的 & 表示引用：values 就是调用者那个 vector 本身。函数里修改它，外面的数据也会变。需要“让函数改我的数据”时用引用。

const 引用：只看不改，还不用复制

一帧点云可能有几十万个点，每次调用都复制一份太慢。const std::vector<double>& values 表示“用原件，但保证不改”。在 SLAM 源码里，你会大量看到 const Eigen::Vector3d& p 这种写法，读法就是“只读地借用 p”。

头文件与源文件：先声明，后定义

大项目会把 double mean(const std::vector<double>& values); 这样的声明（只有函数长什么样）放在 .h 或 .hpp 头文件里，把定义（函数体）放在 .cpp 里。其他文件 #include 头文件就能调用它。读源码时，在 .h 里看接口，在 .cpp 里看实现。

两类常见报错

报错关键词阶段通常原因
no matching function for call to编译参数个数或类型和函数定义对不上
undefined reference to链接只有声明没有定义，或没有把对应的 .cpp/库一起编译链接

编译检查每个文件的写法，链接把各个文件和库拼成一个程序。看到 undefined reference，不要去改函数代码，先查是不是漏了某个源文件或库，这在部署 FAST-LIO2 时也会遇到。

文件：labs/cpp/02_functions.cpp（编译：g++ -std=c++17 labs/cpp/02_functions.cpp -o functions）

C++：需要在 Linux 中编译后运行，命令见上文。

#include <iostream>
#include <vector>

double residual(double position, double measured, double wall = 10.0) {
    return (wall - position) - measured;
}

void shiftAll(std::vector<double>& values, double offset) {
    for (double& v : values) v += offset;
}

double mean(const std::vector<double>& values) {
    double total = 0.0;
    for (double v : values) total += v;
    return total / values.size();
}

int main() {
    std::vector<double> z = {2.9, 3.0, 3.1};
    std::cout << residual(7.0, 3.1) << "\n";
    shiftAll(z, 0.2);
    std::cout << mean(z) << "\n";
    return 0;
}

输出 -0.1 和 3.2。shiftAll 通过引用把 z 中每个数都加了 0.2，所以平均值从 3.0 变成 3.2。注意循环里的 double& v：如果写成 double v，改的只是复印件，z 不会变。mean 的参数是 const 引用，函数里若写 values[0] = 1; 会编译报错，这正是 const 在保护你。

输出 3（即 3.0）。函数改的是副本，main 里的 z 没变。编译器不会报错，因为这在语法上完全合法，只是含义变了。这类 bug 只能靠预测输出、对比结果发现。

改变条件的迁移练习与解析

一句话总结

& 是引用，函数改的就是原件；const & 是只读借用、不复制；undefined reference 是链接问题，先查漏了哪个文件或库。
