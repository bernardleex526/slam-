Python③：函数与调试：把重复写成规则，把报错变成线索

能定义和调用函数，区分 return 与 print，用“五步法”和 assert 定位错误，并让 AI 帮你翻译报错。

先修：04 · Python②：列表和循环：一次处理很多测量

预计用时：2–3 次 × 30 分钟。一次学不完就分开，第二天先闭卷重做上一段。

本课新词（3 个）：函数 function、报错 traceback、断言 assert。随时可查 术语页。

先打个比方

函数像一台榨汁机：放进水果（参数），按下开关（调用），出来果汁（return 的值）。print 只是让你“看一眼”机器内部，并不会把果汁递出来。

比喻只帮你建立直觉；下面用数字、公式和代码把它说准确。

比方→具体问题→手算→代码→解释

从实际问题走到公式

第 02 课的残差公式 h(x)−z 要对每个测量用一次。把它写成函数，就只需要写一次规则。

函数的四个部分

def residual(position, measured, wall=10.0): 中，def 表示“定义函数”，residual 是函数名，括号里是参数，wall=10.0 是默认值（不传就用 10.0）。缩进的部分是函数体，return 把结果交回调用的地方。只定义不调用，什么都不会算；写 residual(7.0, 3.0) 才是调用。

return 和 print 的区别

return 把值交给调用者，可以继续参与计算；print 只是显示在屏幕上，调用者拿到的是 None（“什么也没有”）。新手最常见的 bug：函数里用了 print 没用 return，后面一计算就报 TypeError: unsupported operand type(s) for -: 'NoneType' and 'float'。看到 NoneType，先查函数有没有 return。

读懂一段完整报错

Traceback (most recent call last):
  File "step3.py", line 9, in <module>
    print(residual(7.0))
TypeError: residual() missing 1 required positional argument: 'measured'

从下往上读：最后一行说调用 residual 时少给了一个参数 measured；上一行是出错的代码；再上一行告诉你在第 9 行。修复方法是补上测量值，而不是去改函数。

调试五步法（保留自旧教材，排查一切 bug 的骨架）

  1. 复现：找到能稳定触发问题的最短步骤，写下来。
  2. 定位：读报错最后一行和行号；没有报错但结果不对，就在中间加 print 看哪一步的值开始偏离手算。
  3. 假设：写一句能被验证的猜测，例如“residual 返回了 None”。
  4. 验证：只改一处，重新运行，看猜测对不对。
  5. 记录：把现象、原因、修复写进 Bug 案例库（模板见 AI 陪练手册）。

assert：让程序自己检查

assert 条件, 说明 在条件不成立时立刻停下并显示说明。用已知答案的小例子写几条 assert，以后改代码时一跑就知道有没有改坏。小数比较不要用 ==，要比较差值是否足够小，因为 0.1+0.2 在电脑里并不精确等于 0.3。

把公式落实到每行代码

Python：可直接运行。先写下预测，再运行核对。

def residual(position, measured, wall=10.0):
    predicted = wall - position
    return predicted - measured

def check(position, measured, expected):
    got = residual(position, measured)
    assert abs(got - expected) < 1e-9, (position, measured, got)
    print("通过", position, measured, round(got, 2))

for z in [2.9, 3.0, 3.1]:
    check(7.0, z, 3.0 - z)

三次都显示“通过”，残差分别是 0.1、0.0、−0.1。check 用手算的期望值（3.0−z）核对函数结果；abs(got−expected) < 1e-9 表示“差得足够小就算相等”。如果有一天你把 residual 改坏了，assert 会停下并显示是哪组输入出错。这就是测试的最小形态，仓库 tests 文件夹里的测试是同样的思路。

核对解答与常见错因

先显示一次 0.1（print 的效果），然后在 check 的 assert 行报 TypeError: unsupported operand type(s) for -: 'NoneType' and 'float'。原因是 got 是 None。修复是改回 return，不是在 check 里绕过错误。
