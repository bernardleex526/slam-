世界模型：学习行动后会发生什么

训练最小动作条件预测模型，区分状态估计、预测、规划与强化学习。

从实际问题走到公式

SLAM 估计当前运动与环境；世界模型在行动条件下预测后续状态或观测。比如“向前发一个单位指令，下一步会到哪里？”几何地图可以成为输入，但静态地图本身不等于动作条件预测模型。

s下一步=s+θa；训练目标 Σ[(s+θa)−s实测下一步]²

s 是位置，a 是动作，θ 是实际每单位动作能走多少米。本课合成训练数据满足实际位移约 0.8a，拟合 θ 后，用它预测多个候选动作序列，比较终点离目标有多远。这是可学习动力学的极小例子，不是训练 Dreamer，也不生成视频。

例如从 s=0 去目标 1.6，候选 [1,1]：模型 θ=1 预测终点 2，θ=0.8 预测 1.6。代价可以写为终点误差平方，再加碰撞或动作代价。滚动规划只执行选中序列的第一步，拿新观测更新状态后重新计划，避免盲目执行整段预测。

实际系统的状态常看不全，叫部分可观测。可从历史图像和动作形成内部表示 z，即潜在状态，再预测 z下一步。潜在状态未必是米制坐标，不能未经标定直接当作 SLAM 位置。模型可能预测观测、奖励与终止概率，具体结构因方法而异。

强化学习通过行动得到奖励来学习策略 π，即给定信息如何选动作。累计回报可写为 r₀+γr₁+γ²r₂+…，γ 为 0 到 1 的折扣系数，表达远期奖励权重。Dreamer 系列在学习的模型中想象轨迹以训练行为；这与本课枚举少量动作序列是不同的规划/学习机制。

世界模型容易多步累积误差：θ 比真实值大 0.05，连续 10 次 a=1，即使无其他误差，也会偏 0.5 米。模型在训练中从没见过墙，可能预测穿墙；规划器还可能专挑模型错误的动作。需要独立多步预测评估、真实或仿真闭环评估，以及对未知情况的保守处理。

SLAM、VLN、世界模型的一个组合是：估计位姿与地图 → 从语言确定目标 → 模型预测候选行动后果 → 控制器执行 → 新观测校正。它们相互补充；学完名字并不能跳过标定、数据与评估。

把公式落实到每行代码

actions = [1.0, 2.0, -1.0]
displacements = [0.8, 1.6, -0.8]
theta = sum(a*d for a, d in zip(actions, displacements)) / sum(a*a for a in actions)
position = 0.0
for action in [1.0, 1.0]:
    position += theta*action
print(round(theta, 4), round(position, 4))

theta 的闭式解来自第 7 课对平方损失求导并置零；分母要求动作不全为零。输出 0.8 1.6。完整训练/留出测试/计划比较运行 labs/world_model.py。
