# SLAM：从基础到工程，再到 VLN 与世界模型

下载整个仓库后，双击 **[index.html](index.html)** 开始。GitHub 文件页显示 HTML 源码；不要只下载单个页面。教材离线运行，不需要账号、GPU、ROS 或安装网页依赖。

这版针对“能运行代码，但说不清公式、代码和实际问题如何对应”的学习起点。按能力关卡推进：基础 → 几何 → 估计 → SLAM 系统 → 工程验证 → 学习模型 → VLN / 世界模型。每课含具体问题、数值推演、符号解释、代码对应、提示、解答和迁移题。早期交互实验直接在浏览器操作；Python 实验只使用标准库。

原来的 11 份周教材保留为进阶资料。仓库原本缺少第五周；新增第五周页面是补课导航，不冒充找回的原文。旧页面加上新入口、先修提示，并修复样式和断链；旧工程代码没有逐段重新验证，运行时须按所选上游版本核对。特别注意 FAST_LIO 原仓库 ROS 1 环境不能直接混用 ROS 2 命令。

## 使用方式

1. 首页完成诊断，按错题回到对应基础课。
2. 每次只学一节：先预测，再手算，再运行，再解释变化。
3. 隔天闭卷重做；能解释和迁移后再在页面记录状态。浏览器存储可能受限制，请导出 JSON 备份。
4. 阶段项目提交代码、结果和失败分析。读完课程不等于获得中级工程能力，项目提供检验方法。

学习记录按课和字段分别保存；同时打开不同课程不会互相覆盖。在多个页面修改同一课的同一个字段时，最后一次保存生效。导出会汇集当前浏览器中最新的记录，仍建议定期备份。

## 可执行实验

在仓库目录打开终端。Windows 用 `py`，Linux/macOS 可用 `python3` 替代：

```text
py labs/core.py
py labs/slam_1d.py
py labs/navigation.py
py labs/world_model.py
py -m unittest discover -s tests -v
```

每条命令只运行一个本地程序。详解见教材实验手册，附输入、预期输出与错误定位。实验是教学简化模型，SLAM 项目同时估计位置和未知地标，但仅限一维且已知对应关系；不等价于 FAST-LIO2 或真实 VLN。

## 修改教材

`course/lessons.py` 保存正文；`course/build.py` 生成课程、首页和术语表。修改后执行 `py course/build.py`，再运行测试。`assets/` 保存离线样式与交互逻辑。`RESOURCES.md` 记录一手资料，`MISSION.md` 记录目标，`learning-records/` 记录真实学习证据。

本版内容与旧教材对应关系见首页“回到原教材”。首轮建议按课学习，不按旧周号赶进度。
