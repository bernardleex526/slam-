SLAM 学习实验室术语与符号实验手册一手资料

实验手册

先看对应课的例子，再运行程序。全部 Python 实验只依赖标准库。命令在解压后的仓库目录执行；命令窗口叫终端，当前目录决定相对路径从哪里开始。

无需安装的起步

直接双击 index.html，打开第01、04、08、10、22课的滑块实验。网页不是 Python 编辑器，页面代码展示与运行脚本分开。想修改算法时再进入下面的文件实验。

Python 环境与执行位置

Windows 先在终端输入 py --version，Linux/macOS 输入 python3 --version。若显示 Python 3.x，解释器可用；若找不到命令，先用浏览器实验，或到 Python 官方下载页 安装。安装完成后重新打开终端。不要把代码贴进 PowerShell 当命令执行。

在仓库文件夹里通过文件管理器“在终端打开”，确认能看到 labs 文件夹。Windows 以下用 py，Linux/macOS 替换为 python3。每次运行单独一条命令。若命令说找不到文件，先检查当前目录，不要重新装所有库。

py labs/core.py
py labs/slam_1d.py
py labs/navigation.py
py labs/world_model.py
程序与对应课先预测什么应看到什么动手修改
core.py / 04、08、10旋转后的点、融合位置、像素(2,2)；位置1.04，方差0.04，K=0.2；像素(520,340)把旋转90改为0，先算再运行。
slam_1d.py / 14三条位置与未知地标[0,1.1375,2.05]；地标4.0625；RMSE约0.12910→0.08447将 estimate 的观测参数改为(6,5,4)，位置应不变，地标加2。
navigation.py / 19、21红门对应节点与路径R；[S,A,R]；SPL 0.6667 与0增加另一个red door标签，应报歧义错误。将A与R双向断开，应返回None不可达。
world_model.py / 22拟合系数与两步预测θ=0.799；留出MSE约0.036667→0.000001；计划(1,1)，预测1.598，合成真实1.6；换摩擦后1.0只用零动作训练应报不可辨识；把测试动力学改为0.5，旧模型误差增加。

最小项目交付清单

每个实验提交四项：运行前手算；修改过的代码；实际输出；一句能被实验否定的解释。不要只交截图。运行测试可以检查实现，但不能替你证明理解。

py -m unittest discover -s tests -v

让所有页面共用同一个学习记录来源

可选：在仓库目录运行下列命令。http.server 是 Python 内置的静态网页服务，8765 是端口，127.0.0.1 只在本机监听。在浏览器打开 本机学习首页。此终端保持运行，用 Ctrl+C 结束。若端口被占用，把命令和地址中的8765一起换成8766。

py -m http.server 8765 --bind 127.0.0.1

常见卡点

文件末尾看起来是 .py 但仍不能运行：检查是不是 .py.txt。小数出现极小差别：先按合理容差比较。import labs 失败：从仓库目录运行，或直接运行脚本。C++ 示例需要编译器与 Eigen，本环境未执行 C++ 编译；不要把 Python 实验通过当成 C++ 已通过。
