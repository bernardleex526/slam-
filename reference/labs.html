实验手册

先看对应课的例子，再运行程序。命令在解压后的仓库目录执行；命令窗口叫终端，当前目录决定相对路径从哪里开始。实验分三层：浏览器、Python、Linux（C++ 与部署）。

第一层：无需安装

直接双击 index.html，打开带滑块的课（墙距残差、二维变换、测量融合、相机投影、世界模型）。网页不是 Python 编辑器，页面代码展示与运行脚本分开。

第二层：Python 环境与执行位置

Windows 先在终端输入 py --version，Linux/macOS 输入 python3 --version。若显示 Python 3.x，解释器可用；若找不到命令，先用浏览器实验，或到 Python 官方下载页 安装。详细步骤见 03 · Python①：变量、数字和第一次运行。

在仓库文件夹里通过文件管理器“在终端打开”，确认能看到 labs 文件夹。Windows 以下用 py，Linux/macOS 替换为 python3。每次运行单独一条命令。若命令说找不到文件，先检查当前目录，不要重新装所有库。

py labs/core.py
py labs/slam_1d.py
py labs/navigation.py
py labs/world_model.py
py labs/deploy/check_bag.py

第三层 A：C++ 与 Eigen（Linux / WSL2 / 容器）

需要 g++；Eigen 示例另需 cmake 与 libeigen3-dev（sudo apt install build-essential cmake libeigen3-dev）。

g++ -std=c++17 labs/cpp/01_basics.cpp -o basics && ./basics
g++ -std=c++17 labs/cpp/02_functions.cpp -o functions && ./functions
cd labs/cpp/eigen_demo && mkdir -p build && cd build && cmake .. && make && ./eigen_demo

应分别看到 7.1/7/6.9 与“3 3.5”（20 · C++①：从 Python 到 C++：类型、分号和编译）、−0.1 与 3.2（21 · C++②：函数、引用与 const：数据是复制还是共用）、“2 2”与“1 0”（22 · C++③：Eigen 与 CMake：把矩阵搬进一个小工程）。

常见卡点

文件末尾看起来是 .py 但仍不能运行：检查是不是 .py.txt。小数出现极小差别：先按合理容差比较。import labs 失败：从仓库目录运行，或直接运行脚本。改了 C++ 没效果：忘了重新编译。ros2 命令找不到：你在 ROS 1 环境里，见 23 · ROS 与 TF：数据流必须有时间和坐标 的对照表。
