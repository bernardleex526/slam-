第 1 章 外参标定

1.0 外参是什么（复习 + 深化）

外参 = 两个传感器坐标系之间的变换（第 1、2 周学过）：p_B = R_AB · p_A + t_AB，把 A 系的点变到 B 系。

机器狗身上要标定的外参：

前雷达 ↔ 机体（laser_front ↔ base_link）
后雷达 ↔ 机体（laser_back ↔ base_link）
雷达 ↔ IMU（laser ↔ imu）      ← FAST-LIO2 用的

为什么必须标：出厂值/目测值不准。外参错 1 厘米、1 度 → 融合点云错位 → 建图重影 → 导航撞墙。 这是"小误差大后果"的典型。

1.1 手眼标定：AX = XB（覆盖资料任务）

1.1.1 名字来源

机器臂抓相机拍照的场景：手（机器人末端）动 X，眼（相机）相对固定物动 → 手和眼之间的固定变换 X 满足 AX = XB：

A = 手的两次相对运动（本体坐标系）
B = 眼的两次相对运动（通过观测算出来）
X = 手眼之间的固定外参（要求的！）

1.1.2 思路（Tsai-Lenz 方法）

1. 移动两次（或多次），记录：
   - 手的位置变化 A（机器人告诉你）
   - 眼观测到的变化 B（标定板/特征点算出）
2. 解 AX = XB → 先解旋转（用四元数/李代数），再解平移
3. 多组数据最小二乘求最优 X

映射到雷达：把"雷达"当"眼"，把"机体/IMU"当"手"——机器狗动一动，雷达观测的固定场景变化 = B，机体自身运动 = A，解出 X = 雷达外参。

1.1.3 为什么"动一动就能标"

因为固定物体在两个坐标系里的一致性约束，运动样本越多，X 解越准。标定的本质 = 采集足够多的运动 + 解最小二乘（第 4 周学的）。

一句话总结：手眼标定 = 解 AX=XB：手动的变化 × 固定外参 = 外参 × 眼观测的变化；用多组运动数据最小二乘求外参。

1.2 时间同步（覆盖资料任务，周二）

1.2.1 问题

两个雷达数据到达时时间可能不对齐：

前雷达：帧时刻 t=10.000s
后雷达：帧时刻 t=10.013s    ← 差 13ms
IMU：   t=10.002s ...

如果忽略时间差：用 10.013s 的后雷达数据配 10.000s 的前雷达 → 机器狗在 13ms 内动了几厘米 → 点云错位。运动越快，时间差越致命。

1.2.2 三种同步方案（从硬到软）

方案 原理 精度 成本
硬件时间戳 传感器自带精确时钟（GPS 授时/PTP） 微秒级 高
PPS 同步 秒脉冲对齐各传感器时钟 微秒~毫秒级 中
软件近似同步 用各自时间戳，插值/对齐到统一时间轴 毫秒级 低

工业实践：传感器给时间戳（软件层保证时钟一致）→ 融合算法按时间戳插值（把数据"算"到同一时刻）。

1.2.3 检查方法（周二实验任务）

# 看 bag 里各传感器时间戳
ros2 bag info 你的bag
# 或 Python：读两个话题的 header.stamp，画时间差直方图

目标：前后雷达时间戳差分布：均值？最大偏差？是否超过"运动中 1 个点的误差"。

一句话总结：时间同步 = 让所有传感器用同一个时间轴；运动越快、同步误差影响越大；检查方法 = 对比各话题时间戳分布。

1.3 点云融合策略（覆盖资料任务，周三）

1.3.1 融合四件事（本周核心清单）

① 坐标变换：后雷达点 → 用外参 → 变到前雷达系（或共同参考系）
② 降采样：两个雷达重合区点数翻倍 → 体素滤波统一密度
③ 重合区处理：同一物体被两个雷达看到 → 只保留一边（或按置信度）
④ 动态物体剔除：重合区里"一个雷达看到、另一个没看到" = 可疑动态目标

1.3.2 融合方案设计（周三输出，一页纸）

按这个模板写你自己的方案：

双雷达融合方案（2026-xx-xx）
- 输入：/front_lidar 点云、/back_lidar 点云、外参 T_front_back
- 处理流程：时间对齐 → 坐标变换 → 体素降采样 → 重合区策略
- 重合区策略：以主雷达为准 / 平均 / 动态剔除（我选：...，理由：...）
- 输出：融合点云 /fused_cloud
- 关键参数：体素尺寸、时间窗、重合区判断阈值

1.3.3 常见的坑

  • 重合区点云"发毛"：两雷达精度不同，同一面墙两个厚度 → 降采样后还是双层 → 需要"按距离/入射角加权"。
  • 外参错 = 融合即错：先标定，再融合，别反过来。
  • 时间没对齐 = 动态物重影。

一句话总结：融合四件事 = 变换 + 降采样 + 重合区 + 动态剔除；外参和时间是地基，地基错全错。

2.1 检查 bag 时间戳对齐（周二 20 分钟）

# 读 bag 两个雷达话题的时间戳，画差分布
from rosbags.highlevel import AnyReader
import numpy as np, matplotlib.pyplot as plt

with AnyReader([r"你的bag"]) as r:
    ts_front, ts_back = [], []
    for c, t, raw in r.messages():
        if c.topic == '/front/lidar': ts_front.append(t)
        if c.topic == '/back/lidar':  ts_back.append(t)

# 时间戳单位是纳秒
ts_front = np.array(ts_front) / 1e9
ts_back = np.array(ts_back) / 1e9

# 对每个前雷达帧，找最近的后雷达帧，算差
diffs = []
for tf in ts_front:
    dt = np.abs(ts_back - tf).min()
    diffs.append(dt)
plt.hist(diffs, bins=50)
plt.xlabel('最近后雷达帧时间差 (s)')
plt.title('前后雷达时间戳对齐情况')
plt.savefig('time_sync_check.png', dpi=150)
print(f"平均差: {np.mean(diffs)*1000:.1f} ms, 最大差: {np.max(diffs)*1000:.1f} ms")

结论判断：平均差 < 一个雷达帧周期的一半（如 10Hz → <50ms）算可接受。
